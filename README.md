# Use & Share

Адаптивный интерфейс сервиса аренды вещей. Реализован на React, Vite, Tailwind CSS и компонентах shadcn/ui с Base UI.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:4173](http://localhost:4173). Для сборки используйте `npm run build`, для проверки кода — `npm run lint`.

## Страницы

- `/` — каталог с поиском по названию, расположению и цене.
- `/page` — профиль: аренды, свои предложения, настройки контактов.
- `/page-2?id=...` — объявление, чат и статус аренды.
- `/add-offer` — форма публикации предложения.

Предложения, сообщения и настройки сохраняются в `localStorage` текущего браузера. Фото сохраняется там же; максимальный размер файла — 1 МБ. Серверной части и аккаунтов пока нет. Контакты в исходниках не заданы: их можно заполнить в настройках профиля.

Исходники компонентов shadcn/ui находятся в `src/components/ui/`, а навыки для работы с ними — в `.agents/skills/shadcn/`.

## Структура

- `src/pages/` — четыре страницы приложения.
- `src/components/` — шапка, карточки и форма настроек профиля.
- `src/components/ui/` — исходники компонентов shadcn/ui.
- `src/lib/data.ts` — типы, демонстрационные объявления и работа с `localStorage`.
- `src/index.css` — цветовые токены, шрифты и стили иллюстраций.
- `public/` — ресурсы, используемые сайтом.
