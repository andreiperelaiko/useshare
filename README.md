# Use & Share

Адаптивный интерфейс сервиса аренды вещей. Реализован на React, Vite, Tailwind CSS и компонентах shadcn/ui с Base UI.

## Запуск через Docker

Нужны Docker и Docker Compose. Локально устанавливать Node.js и пакеты из `node_modules` не требуется.

```bash
docker compose up --build
```

Откройте [http://localhost:4173](http://localhost:4173). Файлы `web/src/`, `web/public/`, `web/index.html` и `web/vite.config.ts` подключены к контейнеру: изменения видны без пересборки образа. После изменения `web/package.json` или `web/package-lock.json` снова выполните `docker compose up --build`.

Проверить код в работающем контейнере:

```bash
docker compose exec app npm run lint
docker compose exec app npm run build
```

Готовую статическую сборку можно проверить отдельно через Nginx:

```bash
docker compose --profile production up --build production
```

Она откроется на [http://localhost:4174](http://localhost:4174). Для других портов задайте `USESHARE_PORT` или `USESHARE_PREVIEW_PORT` перед командой. Контейнеры останавливаются командой `docker compose down` (для статической сборки — `docker compose --profile production down`).

Данные профиля, свои предложения и запросы по-прежнему хранятся в `localStorage` браузера, а не в контейнере.

## Запуск без Docker

```bash
cd web
npm ci
npm run dev
```

Откройте [http://localhost:4173](http://localhost:4173). Для сборки используйте `npm run build`, для проверки кода — `npm run lint`.

## Страницы

- `/` — каталог с переключателем предложений и запросов, поиском по названию, расположению и цене или бюджету. По 24 карточки за раз; `/?view=requests` сразу открывает запросы.
- `/page` — профиль: «Мои запросы», «Мои предложения» и настройки контактов и палитры.
- `/page-2?id=...` — объявление, чат и статус аренды.
- `/add-offer` — форма публикации предложения.
- `/add-request` — форма заявки на поиск вещи с описанием, местом, бюджетом и сроками.

Предложения, заявки, сообщения и настройки сохраняются в `localStorage` текущего браузера. Фото сохраняется там же; максимальный размер файла — 1 МБ. Серверной части и аккаунтов пока нет, поэтому заявки пока не видны другим пользователям. Контакты в исходниках не заданы: их можно заполнить в настройках профиля.

В каталоге есть 100 **демонстрационных** предложений и 100 **демонстрационных** запросов. Названия, описания, цены, бюджеты и расположение составлены для примера; это не реальные объявления. Фотографии предложений взяты из Wikimedia Commons. Авторы, ссылки и лицензии перечислены в [IMAGE_CREDITS.md](web/IMAGE_CREDITS.md) и на страницах объявлений.

Исходники компонентов shadcn/ui находятся в `web/src/components/ui/`, а навыки для работы с ними — в `web/.agents/skills/shadcn/`.

## Структура

- `web/` — фронтенд, npm-зависимости, исходники и его конфигурация.
- `web/src/pages/` — страницы приложения и формы предложений и заявок.
- `web/src/components/` — шапка, карточки и форма настроек профиля.
- `web/src/components/ui/` — исходники компонентов shadcn/ui.
- `web/src/lib/types.ts` — типы объявления, заявки, профиля и сообщения.
- `web/src/lib/data.ts` — чтение и сохранение данных в `localStorage`.
- `web/src/data/` — демонстрационные предложения и запросы, сведения об изображениях.
- `web/src/index.css` — цветовые токены, шрифты и стили иллюстраций.
- `web/public/` — шрифты и изображения, используемые сайтом.
- `docker/`, `compose.yaml`, `.dockerignore` — окружение разработки и статической сборки в контейнерах.
