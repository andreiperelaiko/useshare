# Use & Share

Адаптивный интерфейс сервиса аренды вещей. Реализован на React, Vite, Tailwind CSS и компонентах shadcn/ui с Base UI.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:4173](http://localhost:4173). Для сборки используйте `npm run build`, для проверки кода — `npm run lint`.

## Страницы

- `/` — каталог с переключателем предложений и запросов, поиском по названию, расположению и цене или бюджету. По 24 карточки за раз; `/?view=requests` сразу открывает запросы.
- `/page` — профиль: «Мои запросы», «Мои предложения» и настройки контактов и палитры.
- `/page-2?id=...` — объявление, чат и статус аренды.
- `/add-offer` — форма публикации предложения.
- `/add-request` — форма заявки на поиск вещи с описанием, местом, бюджетом и сроками.

Предложения, заявки, сообщения и настройки сохраняются в `localStorage` текущего браузера. Фото сохраняется там же; максимальный размер файла — 1 МБ. Серверной части и аккаунтов пока нет, поэтому заявки пока не видны другим пользователям. Контакты в исходниках не заданы: их можно заполнить в настройках профиля.

В каталоге есть 100 **демонстрационных** предложений и 100 **демонстрационных** запросов. Названия, описания, цены, бюджеты и расположение составлены для примера; это не реальные объявления. Фотографии предложений взяты из Wikimedia Commons. Авторы, ссылки и лицензии перечислены в [IMAGE_CREDITS.md](IMAGE_CREDITS.md) и на страницах объявлений.

Исходники компонентов shadcn/ui находятся в `src/components/ui/`, а навыки для работы с ними — в `.agents/skills/shadcn/`.

## Структура

- `src/pages/` — страницы приложения и формы предложений и заявок.
- `src/components/` — шапка, карточки и форма настроек профиля.
- `src/components/ui/` — исходники компонентов shadcn/ui.
- `src/lib/types.ts` — типы объявления, заявки, профиля и сообщения.
- `src/lib/data.ts` — чтение и сохранение данных в `localStorage`.
- `src/data/` — демонстрационные предложения и запросы, сведения об изображениях.
- `src/index.css` — цветовые токены, шрифты и стили иллюстраций.
- `public/` — шрифты и изображения, используемые сайтом.
